# Aplikasi Expense Tracker (Pencatat Keuangan) dengan Grafik Interaktif
Deskripsi: Aplikasi pencatat pemasukan dan pengeluaran keuangan pribadi yang otomatis merangkum data ke dalam bentuk diagram/grafik visual.  Konsep Utama: Integrasi library grafik (seperti Chart.js), Array Methods tingkat lanjut (reduce, filter, map), serta manajemen form dan validasi data dinamis
